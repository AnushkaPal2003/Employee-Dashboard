# SQL Projects Portfolio

This repository contains multiple SQL projects built for practice and portfolio development. The projects focus on real-world data analysis using relational databases.

## Projects Included
- Employee Data Analysis
- E-Commerce Data Analysis

## Key Skills Used
- SQL Joins (INNER, LEFT)
- Aggregations (SUM, COUNT, AVG)
- Window Functions (RANK, DENSE_RANK, ROW_NUMBER)
- CTEs (Common Table Expressions)
- Data Analysis & Business Insights
- Date & Time Functions

## Tools Used
- Microsoft SQL Server (SSMS)
- SQL

## Purpose
To demonstrate SQL skills through real-world business scenarios and build a strong data analytics portfolio.
