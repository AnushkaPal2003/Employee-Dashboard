# E-Commerce SQL Analysis Project

## Overview
This project focuses on analyzing an e-commerce dataset using SQL.  
The analysis covers customer behavior, sales performance, product insights, and advanced SQL operations using joins, aggregations, window functions, CTEs, and ranking functions.


## Database Used
Microsoft SQL Server Management Studio (SSMS)


## Tables Used

1. customers
2. orders
3. order_items
4. products
5. categories


## Key Analysis Performed

### Customer Analysis
- Total customers
- Repeat customers
- Customers with no orders
- Top spending customers
- Customer segmentation
- Customer ranking based on order count
- First and most recent order analysis

### Sales Analysis
- Total revenue
- Average order value (AOV)
- Monthly revenue trends
- Highest sales month
- Daily revenue trend
- Revenue-generating orders

### Product Analysis
- Best-selling products
- Least-selling products
- Products by revenue contribution
- Product ranking based on sales quantity
- Products with highest discounts
- Average quantity sold per product

### Order Analysis
- Total items per order
- High-value orders
- Delayed orders
- Shipping time analysis
- Cumulative revenue analysis

### Advanced SQL Concepts Used
- INNER JOIN
- LEFT JOIN
- GROUP BY
- HAVING
- CASE WHEN
- Window Functions
    - RANK()
    - DENSE_RANK()
    - ROW_NUMBER()
- Aggregate Functions
    - SUM()
    - COUNT()
    - AVG()
- Date Functions
    - MONTH()
    - DATEDIFF()
